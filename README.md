# Procesos de separación con Google Colab

Notas, ejemplos resueltos y ejercicios en cuadernos de Google Colab sobre **transferencia de masa, absorción-desorción, columnas de absorción y evaporación**. Todo el código está en Python y puede ejecutarse en el navegador, sin instalar nada.

![Python](https://img.shields.io/badge/Python-3.10%2B-blue)
![Licencia](https://img.shields.io/badge/licencia-MIT-green)
![Colab](https://img.shields.io/badge/Google-Colab-F9AB00)

## Objetivo

Ofrecer material abierto y reutilizable para aprender a **diseñar operaciones de separación** mediante transferencia de masa: desde los coeficientes de transferencia hasta el dimensionamiento de columnas de absorción y evaporadores de simple y múltiple efecto.

## A quién va dirigido

- Estudiantes de ingeniería química, farmacéutica, biotecnología, de alimentos y afines.
- Docentes que buscan ejemplos listos para usar en clase.
- Cualquier persona que quiera practicar cálculo de operaciones unitarias con Python.

## Cómo usar los cuadernos

### En Google Colab (recomendado)

1. Abre el cuaderno con el botón **Open in Colab**.
2. Ejecuta la primera celda, que clona el repositorio y habilita las utilidades compartidas:

   ```python
   !git clone -q https://github.com/JManuelRG/Procesos-de-Separacion.git
   import sys
   sys.path.append("/content/Procesos-de-Separacion")
   ```

3. Ejecuta el resto de las celdas en orden.

### En local

```bash
git clone https://github.com/JManuelRG/Procesos-de-Separacion.git
cd Procesos-de-Separacion
python -m venv .venv
source .venv/bin/activate        # En Windows: .venv\Scripts\activate
pip install -r requirements.txt
jupyter lab
```
